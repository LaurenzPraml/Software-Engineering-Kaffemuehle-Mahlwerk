# Sprint 3

Im dritten Sprint sollen alle ausstehenden Requirements realisiert werden. Hierzu wurden im Sequenz- und Kommunikationsdiagramm alle Interaktionen mit der Klasse "DateiManager" ergänzt. Außerdem wurden folgende Requirements für die Umsetzung ausgewählt.

### Umzusetzende Requirements
* 1.1) Die aktuelle Masse an Bohnen im Oberbehälter muss gemessen werden
* 3.5) Die verbleibende Dauer des Mahlvorgangs muss angezeigt werden
* 3.6) Die Mühle muss einen abgeschlossenen Mahlvorgang durch piepen bekannt geben
* 5.2) Die Anzahl an Mahlvorgängen muss bei stromlosigkeit gespeichert bleiben

### Erweiterungen im Software Design

        - Dateipfad: string

    - Methoden:
